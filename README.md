# Cybozu Audit Log SIEM Integrations

SIEM connectors for [Cybozu](https://cybozu.co.jp/) audit logs.

## Available Integrations

| Platform | Status | Documentation |
|---|---|---|
| Microsoft Sentinel | ✅ Available | [sentinel/](./sentinel/) |
| Splunk | 🚧 Coming soon | — |

## Overview

This repository provides connectors that pull Cybozu audit logs into your SIEM platform. Logs are fetched on a pull model using time-range parameters — no customer-side information is stored on the Cybozu backend.
